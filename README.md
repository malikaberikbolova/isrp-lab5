Изменение названия одного варианта использования в текстовом формате видно в git diff мгновенно: одна строка минус, одна плюс, и сразу понятно, что именно изменилось. В PNG то же самое изменение потребовало бы открыть обе картинки рядом и вручную искать отличие глазами, при этом git всё равно показал бы только «файл изменился», без указания, что именно. Текстовый формат проигрывает в наглядности для первого знакомства с диаграммой, но выигрывает там, где важна история изменений, то есть как раз в работе с репозиторием.
